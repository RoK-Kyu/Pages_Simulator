How each one picks a victim

FIFOFirst in, first out

Evicts the page that has been in memory longest, whether or not it is still busy. Cheap to run with a queue, but it can throw out a hot page and is the classic case of Belady's anomaly.

LRULeast recently used

Evicts the page whose last use is furthest in the past. It tracks locality well and never shows Belady's anomaly, but true LRU needs a timestamp or stack update on every access.

LFULeast frequently used

Evicts the page with the fewest uses since it was loaded. Good when popularity is stable; slow to forget a page that was busy long ago. Ties go to the oldest page.

MFUMost frequently used

Evicts the page with the most uses, betting that a heavily used page has finished its work and a newcomer is about to be needed. Rarely wins in practice. Ties go to the oldest page.

Use counts start at 1 when a page is loaded and reset when it is evicted. Every algorithm fills empty frames first, left to right.
